## 0. 一句话定位（spec §9.2 原文，逐字引用，不得改写）

> **RNA 二级结构预测的瓶颈不是表征能力，而是"信任"与"成本"的两难**——物理方法给出校准概率却要付 `O(L³)` 配分函数，深度方法便宜却输出未校准、不合法、跨家族泛化差。我们证明：**单次前向的决策头可以被训练得与精确配分函数边际同等校准**，从而在推理期**完全省去配分函数**；而由此得到的校准置信度进一步支撑**计算自适应折叠**——只在不确定的地方调用精确物理。

**谱系诚实性（必须写进正文，spec §9.2 末段）**：本工作**站在 CONTRAfold / CRF 谱系上**，贡献在于"免 DP 的校准"与"计算自适应"，**而非**首创配分函数框架。

**偏离度声明（spec §0.9.1，必须写进正文）**：

> 本工作**不是"把 Jev 架构搬到 RNA"**，而是**把 Jev 的决策范式从「单决策」推广到「结构化预测」**。三处本质偏离（小选项集 → 指数级结构空间；单决策 → `L²` 决策；无额外计算 → 需 DP）都是这一推广的**必然结果**，而非设计走偏。

## 1. 四段式叙事（spec §9.2）

### 第 1 段：问题——信任与成本的两难

- 现有方法分两类，各自卡住一半：
  - **准但慢**：McCaskill / CONTRAfold 谱系，`O(L³)` 配分函数才有概率；
  - **快但不可信**：UFold / SPOT-RNA 的 sigmoid 输出**未校准**、需启发式后处理才能合法、跨家族泛化差（MXFold2 论文报告 E2Efold 在未见家族上 `F ≈ 0.0361`）。
- **没人回答"这个预测能不能信"**，也没人回答"何时值得花 `O(L³)`"。
- 领域评测缺口：主流只报 F1 / INF，不报 ECE / 可靠性图 / 边际校准。

### 第 2 段：方法——免 DP 的校准决策头（**C1**）

- 核心洞见：把**精确配分函数边际**从「推理时依赖」改为「**训练期教师**」（spec §5.0.1 双模式设计）。
- 机制：单次前向 → 决策头直接输出配对概率 `p̂^head`；训练目标同时匹配**精确边际**（蒸馏）与**校准**（RLCD 式目标）。
- 关键点：**精确边际使校准目标可精确求梯度、无需采样估计**（概率空间；不得声称可廉价反传穿过配分函数，spec §5.8.2）。
- 结果主张：推理期不跑配分函数，概率仍与精确边际同等校准（判据 **S7**：ECE 差 ≤ 0.02）。
- **诚实边界**：C1 的成立以 **CDPFold 校准对比**为前提（阻塞项，spec §0.9.4）；"免 DP"本身不是空白。

### 第 3 段：系统——计算自适应折叠（**C2**）

- 校准置信度成为**计算分配的控制器**：低置信区域才升级到精确物理（System-2）。
- 把"何时花 `O(L³)`"从工程启发式变成**模型可决策**的问题（判据 **S6**：匹配平均 FLOPs）。
- **核心架构是层级决策级联**（spec §5.0.2）：决策从 `O(L²)` 个碱基对降到 `O(L)` 个螺旋级决策 + 局部细化。
  - 数学依据：非交叉匹配的弧图是**森林**，Nussinov 递推即其树分解（层级分解是结构空间的固有性质，不是强加的归纳偏置）。
  - 物理依据：螺旋是进化保守的功能单元。
  - 与带状化的本质区别：带状化**牺牲长程配对**（`O(L·B²)`，工程 hack）；层级级联**保留长程配对**（粗粒度块对可覆盖任意距离）。
  - 判据：**S8**（复杂度收益）+ **S9**（不牺牲长程配对）+ **P6**（L0 螺旋召回 ≥ 0.98）。
- **论文骨架 = C2（骨架） + C1（卖点） + C3/C4（配套）**（spec §0.9.2）。

### 第 4 段：测量——校准优先评测协议（**C3/C4**）

- 把 ECE / 可靠性图 / 边际校准 / 后验对数似然 / **结构层面校准** / "合法化代价"作为**一等指标**引入本领域。
- 填补领域评测缺口，且直接服务于下游（设计、变异解读）。
- 定位：**支撑性工作**，"提出指标"在顶刊偏弱，不作主打。

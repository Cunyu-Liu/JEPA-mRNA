## 1. 三轮审稿人自检（共 8 个实质问题）

> 三轮自检记录比任何"创新点罗列"都重要。**一个经不起审稿人一击的架构，写得再长也没有价值。**

### 第一轮（spec §0.7）：修掉"不成立"的问题——5 个

#### 问题 1（**致命**）：速度主张与精确边际自相矛盾

- **原文缺陷**：同时声称 ① 校准置信度 = inside-outside 精确边际 `p̂_ij`（需 `O(L³)` 配分函数 DP）；② 相对 McCaskill 配分函数加速 ≥ 50×（需不跑 `O(L³)` DP）。**二者不可兼得**：若推理时仍需 inside-outside，总代价 `O(L²d)+O(L³)` **反而比 McCaskill 更慢**。
- **修正**：改为**双模式设计**，把「**免 DP 的校准决策头**」确立为核心论点（spec §5.0.1）。
  - System-1 快速模式：`1×` 前向 → 决策头**直接输出校准概率**；带状 DP 求合法结构；**不跑配分函数**。
  - System-2 精确模式：仅在置信度不足处升级为 inside-outside。
  - **副作用（正面）**：RLCD 从"装饰"变为"承重"——它正是「跳过 `O(L³)` 配分函数、仍能给出校准概率」的原因。

#### 问题 2（**严重**）：Gibbs 框架并非首创，本质是 CONTRAfold / CRF 的神经化

- **事实**：非交叉结构空间上的对数线性模型 + DP 精确配分函数 + 条件似然 + `(y-p̂)` 梯度 + inside-outside 边际 = **CONTRAfold（Do, Woods & Batzoglou, 2006）及其所属 CRF / 结构化预测框架的教科书内容**。
- **修正**：删除一切"首次提出 Gibbs 框架"类表述；把 CONTRAfold / CRF **明确列为最接近的先验工作**并设为头号对比对象；新颖性收窄为「免 DP 的校准」+「计算自适应」。

#### 问题 3（**严重**）：`MLP_T` 零初始化「起点 = 纯 Turner 模型」表述不准确

- **事实**：Nussinov DP **只含堆叠项**，不含环熵、coaxial stacking、终端错配等；`MLP_T=0` 得到的是「**Nussinov DP + Turner 堆叠能**」，**不等于 ViennaRNA 的 MFE 结构**。
- **修正**：精确表述为「Nussinov + Turner 堆叠能」，并**明确声明它不等价于 ViennaRNA**；相应消融的对照基线改为该基线而非 ViennaRNA。

#### 问题 4（**中等**）：共转录决策顺序是装饰性的

- **事实**：共转录 5'→3' 顺序 = Nussinov 从左到右填表顺序，只是**重新表述** DP 的固有顺序，**不改变分布、不带来新能力**。
- **修正**：**从创新点降级为消融项**（H4 改为不预设方向）。若要做成真创新须实现**流式增量折叠**（每新增碱基 `O(1)` 更新概率矩阵）——那是**另一篇论文**，本工作不做。

#### 问题 5（**中等**）：H1「非法结构率 = 0」近乎同义反复

- **事实**：任何带约束解码的方法都能做到 0%（UFold + 约束后处理同样为 0），该指标无区分度。
- **修正**：H1 改为测量「**强制合法性所付出的精度代价**」——同一模型在「DP 层内建约束」与「无约束接触图 + 启发式后处理」两种解码下的 **F1 落差**。

### 第二轮（spec §0.8）：修掉"不够好"的问题——3 个

#### 问题 6（**严重**）：C1「免 DP」的表述过宽，新颖性被稀释

- **事实**：**CDPFold 用条件扩散模型直接输出 `L×L` 配对概率矩阵**，UFold / SPOT-RNA 的接触图本质也是概率矩阵。故「不跑 DP 就有概率」**不是空白**。
- **修正**：C1 表述**收紧**——空白不在"免 DP"，而在「**免 DP 且概率经过校准**」。标题从"免 DP 的校准决策头"改为「**免 DP 的校准**」，重音落在**校准**；必须显式引用 CDPFold / UFold / SPOT-RNA 作为"免 DP 但未校准"的对照；新颖性落点改为「**我们证明免 DP 的概率可以被训练到与精确边际同等校准**」（判据 S7）。
- **连带后果**：CDPFold 校准对比成为**全局阻塞项**——若其校准与本文相当，C1 崩塌，论文骨架退为 C2 + C4。

#### 问题 7（**核心**）：`O(L²)` 瓶颈被"带状化"敷衍，而非架构性解决

- **原文缺陷**：用 banded attention / 带状 DP 缓解 `O(L²)`。这只是**工程 hack**，且**带状化牺牲长程配对**——恰恰是 RNA 结构最需要的能力。
- **修正**：提出**层级决策级联**（spec §5.0.2）作为核心架构，把决策数量从 `O(L²)` 个碱基对降到 `O(L)` 个螺旋级决策 + 局部细化。**这是架构性的复杂度改进，不是调参。**

#### 问题 8（**中等**）：泛化才是领域真正痛点，原稿却只把它当评测项

- **事实**：bpRNA-new 上**所有方法都差**（E2Efold F≈0.0361）。速度再快、校准再好，若 OOD 精度不提升，领域价值有限。
- **修正**：把**泛化**提升为与 C1/C2 并列的一等目标；明确**层级架构本身即是泛化机制**（螺旋是进化保守功能单元，螺旋级参数化更少、更可迁移）；新增假设 **H7**。

### 第三轮（spec §0.9）：回归 Jev——偏离度审计与改进价值评估

**偏离度审计结论（必须写进论文）**：

> 本工作**不是"把 Jev 架构搬到 RNA"**，而是**把 Jev 的决策范式从「单决策」推广到「结构化预测」**。三处本质偏离（小选项集 → 指数级结构空间；单决策 → `L²` 决策；无额外计算 → 需 DP）都是这一推广的**必然结果**，而非设计走偏。

**改进价值评估（诚实结论）**：此前的"创新点清单"里有大量充数项——Gibbs 框架 / 精确似然（低）、Turner 残差先验（低-中）、构造性对称（低）、隐式微分可微 DP（低）、共转录决策顺序（无）、JEPA 线（负）。据此把贡献结构从"4 条并列"砍到「**2 真贡献 + 2 支撑 + 5 实现手段（不主张）**」。

## 2. 六条禁止表述（spec §2.4）——**写作红线**

| # | 禁止主张 | 原因 |
|---|---|---|
| 1 | ❌ **不主张首创 Gibbs / 配分函数框架** | CONTRAfold（Do et al. 2006）与 CRF 谱系已具备：非交叉空间上的对数线性模型、DP 精确配分函数、条件似然训练、`(y-p̂)` 梯度、inside-outside 边际。**这些是教科书内容** |

## 5. 泛化主张的措辞规则（spec §0.9.3）

| ❌ 不得写 | ✅ 应写 |
|---|---|
| "OOD 精度更高" / "跨家族精度超越基线" | "**OOD 衰减更小（更鲁棒）**" / "跨家族场景下退化更小" |

**理由**：泛化瓶颈是数据与问题本质，不是架构。物理先验（Turner 参数是物理常数，不随家族漂移）+ 螺旋级参数化提供了**更小退化**的机制支撑，这比"绝对值更高"更可辩护。除非 H7 意外成立且效应显著，否则一律采用"更小衰减"口径。

## Why

RNA 二级结构预测当前有三条路线，各自卡在不同痛点上：

1. **热力学 DP**（ViennaRNA/McCaskill、RNAstructure、CONTRAfold、LinearFold）：物理可解释、保证合法结构，但精度受限，且**配分函数/配对概率的计算 `O(L³)` 且常数很大**——慢。
2. **判别式深度学习**（UFold、SPOT-RNA、MXfold2、E2Efold）：精度更高，但输出是接触图，需**启发式后处理**才能变成合法结构，后处理会破坏物理约束；E2Efold 类还需展开 DP 求解器，推理慢。且**跨家族泛化极差**——MXFold2 论文报告 E2Efold 在未见家族上 F ≈ 0.0361。
3. **生成式/自回归结构模型**：逐 token 解码结构，`O(L)` 次前向，慢，且会「结构幻觉」——生成不合法括号串。

**Jev 的核心洞察同时命中这三条路线的痛点**：它不生成字符串，而是把生成问题重构为**受限假设空间上的校准决策**——一次前向直接读出候选选项 logits，softmax 得到校准概率，**输出 token 数恒为 0**，且类型安全、零格式幻觉。

把这一范式**纯血迁移**到 RNA 二级结构预测：

> **不再"生成括号串"，而是"对每个候选碱基配对做一次校准决策"，用单次前向替代一切慢速求解。**

## What Changes

- **新增**：把 RNA 二级结构预测重构为「受限配对空间上的校准决策」，架构完全按 Jev 决策模型范式设计（受限选项集 → 单次前向 → logits → 校准概率 → 无生成 → 类型安全 → 置信度路由）。
- **新增**：统一数学框架——在**非交叉结构空间上定义 Gibbs 分布**，用 Nussinov sum-product 精确算配分函数 `Z(x)`、inside-outside 精确算边际 `p̂_ij`、max-product 精确求 MAP。这使本方案成为**McCaskill 配分函数模型的学习化推广**：把固定 Turner 参数替换为学习的上下文相关打分函数。
- **新增**：由框架自然导出的三点优势——① 校准置信度 = 精确边际概率（非启发式）；② 输出结构必然合法（非法结构率恒为 0）；③ 训练梯度形如 `(y - p̂)·∇s`，即**带非交叉约束的 logistic 回归**。
- **新增**：**决策蒸馏预训练**（Jev 式 System-1/System-2 分工）——用热力学配分函数作慢速教师生成校准概率软标签，蒸馏到单次前向的学生决策头。这是纯 Jev 路线的预训练方式，**不使用 JEPA / 隐空间预测 / EMA teacher**。
- **新增**：**RLCD-RNA（面向校准配对决策的强化学习）**——对齐 Jev 的 **RLCD** 训练层（J9）。Jev 的置信度可信不是架构副产品，而是被显式训练出来的；只搬架构不搬 RLCD 只得一半。本方案以 Brier/对数评分 + 可微软 ECE 为奖励，直接优化配对概率的**校准**（§5.8）。**须标注为"RLCD 启发式自设计目标"，因 Jev 的 RLCD 算法未公开。**
- **新增**：真实可用数据盘查（含实测落盘状态与获取风险）、量化成功标准、投稿目标与叙事定位、资源与排期计划。
- **修改**：训练目标为「精确似然（硬标签）+ 热力学决策蒸馏（软标签）+ RLCD 校准（校准目标）」三项联合，**移除原 JEPA 隐空间预测目标**。
- **BREAKING**：**移除** JEPA 线（student/EMA teacher、`L_pred`、`L_region`、`L_var`/`L_cov`、区域因子分解）。理由见 §0.6。
- **不修改**：`rna-jepa/` 的既有基础设施与既有结论（R3 闸门、tokenization 等价性证明、ORF 等价性证明）作为工具复用，不推翻。

## 0. Jev 技术剖析（证据基线）

### 0.1 Jev 是什么（产品事实）

Jev 是 **TypeSafe AI** 于 **2026-09-15** 发布的模型，自称第一个 **System One Model**（取自卡尼曼快/慢思考二分），口号 **"Decisions, not strings"**。创始人 **Diogo Almeida** 是 RLHF 的核心贡献者，其公开表态是对 RLHF 的反思。

**三层分工定位**：`LLM 负责生成，Jev 负责决策，code 负责执行`。

### 0.2 Jev 的三层结构

**第 1 层：接口层（State → Decision）**

| 环节 | 内容 |
|---|---|
| 输入 | 一份 **state**——可以是文本、JSON 对象或文本数组，外加"要判断什么"的说明 |
| 输出 | 一个**结构化 Decision**，类型为 **`Choice` / `Score` / `Probability`** |
| 关键性质 | 输出是**软件可直接执行**的结果（类型安全），而非待解析的文本 |

**第 2 层：架构层（读 logits，不生成）**

- 输出阶段**不逐个生成文本 token**；而是把预先定义的选项作为目标位置，**直接读取模型在该位置的 logits**，softmax 得到概率。
- 社区复刻实测：**`output_tokens` 恒为 0**——输入端 359–652 token，输出端一个字节都没有。
- 社区复刻给出的规模：**421M encoder + 2 层决策头**，一次前向直接读出选项 logits。
- 开源复刻 **OpenJev**（MIT）路线：基于开源 LLM（如 Qwen3.5-4B），**不重新训练**，只读取给定选项位置的 logits。
- 社区另有 102 行的极简复刻（冻结 LLM + 读 option logits），在 TypeSafe 公开子集上一致率 **84.5%**。
- 社区结论一句话：**"它不是小号 LLM，是把分类器做成了 LLM。"**

**第 3 层：训练层（RLCD）——最核心、也最容易被忽略**

Jev 的训练方法名为 **RLCD（Reinforcement Learning for Calibrated Decisions，面向校准决策的强化学习）**。

| 维度 | RLHF（对话 LLM） | **RLCD（Jev）** |
|---|---|---|
| 优化目标 | 让回答"看起来符合人类偏好" | 让**决策概率经过校准** |
| 判据 | 人类偏好排序 | **"我说 80% 的时候，现实中是否真的大约 80% 正确"** |
| 对齐对象 | 人类喜好 | **概率校准（calibration）** |

> **这是 Jev 范式迁移中最关键、也最常被忽略的一环**：Jev 的"置信度可信"不是架构的副产品，而是**被显式训练出来的**。只搬架构、不搬 RLCD，就只得到一半。

截至本 spec 撰写，**Jev 没有公开发表的论文或技术报告**。公开信息全部来自厂商表述、技术媒体转述与社区开源复刻。**明确未公开的有四项**：

### 0.4 可安全引用的机制内核（J1–J9）

| # | 机制 | 说明 |
|---|---|---|
| J1 | **受限假设空间决策** | 输出是对**候选集 `C = {c₁..c_k}` 的概率分布**，而非自由文本 |
| J2 | **单次前向、无解码** | 一次前向直接读 option logits；`output_tokens ≡ 0`；速度来自"1 次前向"而非"更小的模型" |
| J3 | **类型安全 / 零格式幻觉** | 输出被约束在封闭假设空间内，**结构上不可能**产出非法格式 |
| J4 | **校准置信度** | 概率经校准，有精确数学含义，可作下游路由依据 |
| J5 | **置信度三分支路由** | 高置信自动执行 / 中置信人工确认 / 低置信转交更慢的推理模型 |
| J6 | **System 1 / System 2 分工** | 快决策模型与慢推理模型互补，由 harness 调度确定性代码与决策模型 |
| **J7** | **State 抽象接口** | 输入是通用的 **state**（文本 / JSON / 数组），不绑定单一模态 |
| **J8** | **结构化输出类型** | 输出是 `Choice` / `Score` / `Probability` 三种可执行类型，而非文本 |
| **J9** | **RLCD：校准决策强化学习** | 训练目标直接对齐**概率校准**，而非人类偏好或单纯似然 |

### 0.6 为什么移除 JEPA 线（必须记录的理由）

**证据状态：已核验（来自本项目既有实验记录）**

本项目早期曾走 JEPA（联合嵌入预测架构）路线。既有记录 `rna-jepa/records/` 给出三条**否定性证据**：

1. **区域均值摘要目标几乎立即饱和**：cos 相似度 60 步内达 0.993，`L_JEPA` 降到 0.02–0.05；提高掩码率（0.30/0.50）无法修复——问题在目标本身易被线性读出解决。
2. **因子探针的对照是空操作**：K 个学习块正交铺满隐空间，线性探针旋转不变 → 学习基与随机基**数值完全相同**（bal_acc 0.933 vs 0.933）。改用秩匹配随机子空间后，学习因子相对随机子空间**无优势**（0.908 vs 0.908），故原假设 C3 **不被证据支持**。
3. **结论**：JEPA 线在本任务上缺乏可辩护的增益。

因此本 spec **移除 JEPA**，转向纯血 Jev 路线：**用决策蒸馏（J6 的 System-1/System-2 分工）+ RLCD 式校准训练（J9）替代隐空间预测预训练**。这既符合用户的明确要求，也与既有证据一致。

### 0.7 审稿人视角自检：发现并已修正的五个实质问题

> 本节是规范的自审记录。**它比任何"创新点罗列"都重要**——一个经不起审稿人一击的架构，写得再长也没有价值。

#### 问题 1（**致命**）：速度主张与精确边际自相矛盾

**原文的缺陷**：规范同时声称两件事——

- §5.0：「校准置信度 = inside-outside 精确边际 `p̂_ij`」→ **需要 `O(L³)` 配分函数 DP**
- §8.3 S1：「相对 McCaskill 配分函数加速 ≥ 50×」→ **需要不跑 `O(L³)` DP**

**二者不可兼得。** 若推理时仍需 inside-outside 求边际，总代价为 `O(L²d) + O(L³)`，**反而比 McCaskill 的 `O(L³)` 更慢**。原规范的核心速度主张因此**不成立**。

**修正（本规范最重要的改动）**：改为**双模式设计**，并把「**免 DP 的校准决策头**」确立为核心论点（见 §5.0.1）：

| 模式 | 计算 | 用途 |
|---|---|---|
| **System-1 快速模式** | `1×` 前向 → 决策头**直接输出校准概率**；带状 DP 求合法结构 | 默认；**不跑配分函数** |
| **System-2 精确模式** | 仅在置信度不足处升级为 inside-outside | 低置信回退 |

**这一修正使 RLCD 从"装饰"变为"承重"**：RLCD 正是「跳过 `O(L³)` 配分函数、仍能给出校准概率」的**原因**。速度主张与校准主张由此统一。

#### 问题 2（**严重**）：Gibbs 框架并非首创，本质是 CONTRAfold / CRF 的神经化

**原文的缺陷**：把「非交叉结构空间上的对数线性模型 + DP 精确配分函数 + 条件似然 + `(y-p̂)` 梯度 + inside-outside 边际」当作本方案的理论创新。

**事实**：这正是 **CONTRAfold**（Do, Woods & Batzoglou, 2006）及其所属的**条件随机场 / 结构化预测**框架的**教科书内容**。Andronescu 等 2007 的 RNA 折叠参数估计工作、MXfold2、E2Efold 也都在同一脉络上。审稿人会直接指出：**"这是 CONTRAfold 把线性打分函数换成神经网络，属增量工作。"**

**修正**：

- **删除**一切"首次提出 Gibbs 框架"类表述
- 把 **CONTRAfold / CRF 明确列为最接近的先验工作**，并在 §7.2 设为**头号对比对象**
- 真正的新颖性**收窄**为 §0.7 末尾的三条贡献（C1/C2/C3），不再声称理论首创

#### 问题 3（**严重**）：`MLP_T` 零初始化「起点 = 纯 Turner 模型」表述不准确

**原文的缺陷**：声称 `MLP_T` 置零时"训练起点等价于纯 Turner 热力学模型"。

**事实**：Nussinov DP **只含堆叠项**，不含环熵、coaxial stacking、终端错配等；因此 `MLP_T=0` 得到的是「**Nussinov DP + Turner 堆叠能**」，**不等于 ViennaRNA 的 MFE 结构**。

**修正**：精确表述为「Nussinov + Turner 堆叠能」，并**明确声明它不等价于 ViennaRNA**，相应消融的对照也改为该基线而非 ViennaRNA。

#### 问题 4（**中等**）：共转录决策顺序是装饰性的

**原文的缺陷**：把「共转录 5'→3' 顺序 = Nussinov 从左到右填表顺序」列为创新点（I3 的一部分、H4）。

**事实**：这只是**重新表述**了 DP 的固有顺序，**不改变分布、不带来新能力**。审稿人会视为修辞。

**修正**：**从创新点降级为消融项**。若要做成真创新，须实现**流式增量折叠**（每新增一个碱基 `O(1)` 更新概率矩阵，支持边转录边预测）——但那是**另一篇论文**，本工作不做。

#### 问题 5（**中等**）：H1「非法结构率 = 0」近乎同义反复

**原文的缺陷**：把「非法结构率 = 0」作为核心假设 H1 的验证目标。

**事实**：**任何带约束解码的方法都能做到 0%**（UFold + 约束后处理同样为 0）。该指标无区分度。

**修正**：H1 改为测量「**强制合法性所付出的精度代价**」——即同一模型在「DP 层内建约束」与「无约束接触图 + 启发式后处理」两种解码下的 **F1 落差**。这才是有区分度的科学问题。

#### 自检后的三条真实贡献（收窄后）

| ID | 贡献 | 为什么不是增量 |
|---|---|---|
| **C1** | **免 DP 的校准决策头**：训练一个单次前向的头，使其配对概率与**精确配分函数边际**同等校准，从而在推理时**完全跳过 `O(L³)` 配分函数**。机制：精确边际作蒸馏目标 + RLCD 式显式校准训练（**精确边际使校准目标可精确求梯度、无需采样**） | CONTRAfold 必须跑 `O(L³)` DP 才有概率；LinearPartition 用同物理近似换速度；UFold/SPOT-RNA 的 sigmoid 输出**未经校准**。**"免 DP 且校准"是空白** |
| **C2** | **计算自适应折叠（compute-adaptive folding）**：置信度门控的升级机制——只在低置信区域调用精确物理，实现**变分辨率**的折叠。**（据我们所知）**把"何时值得花 `O(L³)`"变成模型可决策的问题 | 现有方法要么全程精确、要么全程近似；**按需分配计算是 RNA 折叠的新能力** |
| **C3** | **校准优先的评测协议**：把 ECE / 可靠性图 / 边际校准 / 后验对数似然作为**一等指标**引入 RNA 二级结构预测，并报告"合法化代价" | 该领域主流只报 F1/INF；**校准评测本身是领域缺口**，且直接服务于下游（设计、变异解读） |

> **注意 C1 与 C2 的关系**：C1 提供"便宜且可信的概率"，C2 消费它。二者构成一个闭环——**没有 C1 的校准，C2 的门控就没有依据**；没有 C2，C1 的校准只是指标好看。这是本架构"真正解决问题"的地方。

### 0.8 审稿人自检（第二轮）：三个更深的问题

> 第一轮修掉了"不成立"的问题；第二轮针对"不够好"的问题。**用户要求的是优秀的、有独立思想的架构，而非勉强能过审的架构。**

#### 问题 6（严重）：C1「免 DP」的表述过宽，新颖性被稀释

**事实**：**已有工作直接预测配对概率矩阵而无需 DP**——**SPOT-RNA / SPOT-RNA2 / UFold** 的最后一层 sigmoid 直接输出 `L×L` 配对概率矩阵（再阈值化得结构），**不跑配分函数**；CDPFold 亦输出配对概率（但随后仍用 DP）。故「不跑 DP 就有概率」**不是空白**。

> **2026-09-24 勘误**：本节原写"CDPFold 用条件扩散模型直接输出 `L×L` 配对概率矩阵"——**该描述有误**。CDPFold 实为 **CNN + 动态规划**（Front Genet 10:467, 2019），标题即 *...Based on Convolutional Neural Network and Dynamic Programming*；它既非扩散，也**不免 DP**。已据此修正 §0.9.4 / §7.2.1 / Task 10.8。详见 `spec/benchmark_decision.md` §1。

**修正**：把 C1 的表述**收紧**——空白不在"免 DP"，而在「**免 DP 且概率经过校准**」。相应地：

- C1 的标题从"免 DP 的校准决策头"改为「**免 DP 的校准**」——重音落在**校准**上
- 必须显式引用 **UFold / SPOT-RNA / SPOT-RNA2** 作为"免 DP 但未校准"的**头号对照**，并在 §7.2 加入对比；CDPFold 降级为普通基线（且权重公开性未核实）
- 新颖性主张的落点从"我们不需要 DP"改为"**我们证明免 DP 的概率可以被训练到与精确边际同等校准**"（S7 是判据）
- **禁止表述**：不得写"我们首次实现单次前向输出配对概率矩阵"——SPOT-RNA/UFold 已做过

#### 问题 7（**核心**）：`O(L²)` 瓶颈被"带状化"敷衍，而非架构性解决

**原稿的缺陷**：用 banded attention / 带状 DP 缓解 `O(L²)`。但这只是**工程 hack**，而且**带状化牺牲长程配对**——恰恰是 RNA 结构最需要的能力（长程三级相互作用对应的二级配对）。审稿人 Q5 会直接击穿。

**修正**：提出**层级决策级联（§5.0.2）**作为核心架构。它把决策数量从 `O(L²)` 个碱基对降到 `O(L)` 个螺旋级决策 + 局部细化——**这是架构性的复杂度改进，不是调参**。

#### 问题 8（中等）：泛化才是领域的真正痛点，原稿却只把它当评测项

**事实**：bpRNA-new 上**所有方法都差**（E2Efold F≈0.0361）。速度再快、校准再好，若 OOD 精度不提升，领域价值有限。审稿人会问"你解决了什么真问题"。

**修正**：

- 把**泛化**提升为与 C1/C2 并列的一等目标，而非仅评测项
- 层级架构本身**即是泛化机制**：螺旋级决策的参数化比碱基级**更少、更可迁移**（螺旋是进化保守的功能单元，碱基级配对模式在家族间漂移更大）
- 新增假设 **H7**：层级参数化在 bpRNA-new 上的 F1 优于扁平 `L×L` 参数化

#### 0.9.3 泛化性判断（诚实估计）

**有利因素（真实的）**：

1. **物理先验跨家族不变**——Turner 参数是物理常数，不随家族漂移。热力学蒸馏 + 残差先验让模型**起点就是物理模型**，在 OOD 上不会崩得那么厉害。**这是我们最强的 OOD 武器。**
2. **螺旋级参数化更少、更可迁移**（H7 的机制依据）——螺旋是进化保守功能单元。
3. 训练信号有两条腿：bpRNA-1m 硬标签 + 20 GB 无标签语料的热力学软标签。

**不利因素（必须承认的）**：

1. **结构标注只有 ~102k，且家族集中**——这是硬约束，架构无法突破。
2. **领域已知所有方法在 bpRNA-new 上都差**（E2Efold F≈0.0361）。
3. **我们的架构创新主要解决复杂度，不是泛化**——H7 是"顺带的机制假设"，不是主设计目标。
4. 无标签语料**无结构标签**，只能做热力学蒸馏，能提供的帮助有限。

**分场景估计**：

| 场景 | 预期 | 理由 |
|---|---|---|
| **同源测试（ArchiveII 去冗余）** | 达到或略超最强基线 | 这是"拟合能力"问题，架构与数据够用 |
| **跨家族（bpRNA-new）** | **最不确定**。合理预期：**显著优于 E2Efold，接近或略超 MXfold2**，但**不太可能大幅突破** | 泛化瓶颈是数据与问题本质，不是架构 |
| **长链** | 有望优于扁平头（C2 的复杂度优势） | 复杂度是长链的真实瓶颈 |
| **OOD 衰减幅度** | **有望比基线更小**（物理先验 + 螺旋级参数化） | 比"OOD 绝对值更高"更可辩护 |

**关键判断（据此调整论文定位）**：

> **不要把泛化当作主打卖点。** 除非 H7 意外成立且效应显著，否则应把泛化主张**从"OOD 精度更高"改为"OOD 衰减更小（更鲁棒）"**——后者有物理先验的机制支撑，更可辩护。

**据此的诚实论文定位**：

> 我们用**层级决策级联（C2）**解决了 RNA 折叠的复杂度瓶颈，用**免 DP 的校准（C1）**让决策可信，用**计算自适应（C3）**把计算花在需要的地方；同时借助**物理先验的归纳偏置**在跨家族场景下保持**鲁棒性**（而非宣称精度突破）。

#### 0.9.5 第二轮回归审计（代码级核验，2026-09-24）

> 第一轮审计（§0.9.1–§0.9.4）比对的是**范式**。第二轮直接读代码与运行配置，**结果比第一轮严厉**：三条发现，其中两条**推翻了规范此前的自我判断**。

**发现 A（严重）：C2「层级决策级联」不在训练与评测路径上，且当前实现与目标函数不相容。**

- **证据（代码）**：`train_decision.build_decision_model()` 只构造 `FlatDecisionHead`；`eval/ss/evaluate_decision.py` 只吃 `DecisionModel`。`HierarchicalCascade` 与 `LengthAdaptiveDispatcher` 在 `decision_head.py` 中被实现，**没有任何调用点**。
- **证据（数学）**：目标函数 `L_NLL = log Z(x) − Σ_(i,j)∈gt s_ij`，其中 `Z` 是**整个非交叉结构空间**上的配分函数。而 `HierarchicalCascade.l2()` 把非活跃块对外一律写 `-inf`（驱动里被替换为 `NEG_BIG = -1e4`）。于是 `log Z` 是在一个"绝大多数候选对被判为 −1e4"的矩阵上求和的，**它描述的已不是模型能产出的那个分布**，`L_NLL` 因此失去意义。
- **判定**：C2 **不是"尚未验证"，而是"尚未成为可用架构"**。它需要一个**分层目标函数**（L0 块对 / L1 螺旋 / L2 局部各自成项、各自归一），而不是复用扁平头的 Gibbs 目标。
- **处置**：见本节「修复清单」第 1 项。**在修复并通过 P6（L0 螺旋召回 ≥ 0.98）之前，论文不得把 C2 写成"已实现的贡献"，只能写成"提出的架构"。**

**发现 B（严重）：当前三臂训练的编码器是随机初始化，且训练量约为 0.56 个 epoch —— 必然欠训练，不得作为科学结论。**

- **证据**：`encoder.build_encoder("35M")` 在 `backbone="custom"` 下直接返回 `RNAEncoder(n_layer=6, d_model=512, n_head=8, d_ff=2048)`，**无任何 checkpoint 加载路径**。三臂配置为 `--steps 3000 --batch-size 2`，即 **6,000 条样本 / 10,682 条语料 ≈ 0.56 epoch**。
- **判定**：该组运行**只能验证通路**，其 F1/ECE **不得**与 UFold / SPOT-RNA / MXfold2 等已训练充分的基线横向比较，更不得写进论文的结果表。
- **处置**：见「修复清单」第 2 项。

**发现 C（中等）：目标函数是按序列**求和**、未按长度归一，损失曲线跨长度桶不可比。**

- **证据**：`harness.negative_log_likelihood` 返回 `log Z(x) − Σ_(i,j)∈gt s_ij`，**没有除以配对数或长度**。语料长度 p50 = 104、p90 = 225、max = 498（实测），而 `iter_batches` 按长度分桶 → 批间损失天然相差数倍（实测日志中相邻两步 99.09 / 59.67 / 72.32）。
- **判定**：**梯度的逐对形式 `p̂_ij − y_ij` 是正确的、有界的**，所以这不构成"梯度错误"；但（a）**损失值不可跨步/跨臂比较**，（b）`grad_clip=1.0` 而裁剪前范数实测 **40–673**，**每一步都被裁死**，实际执行的是"定步长归一化梯度下降"，有效步长随批次长度波动。
- **处置**：见「修复清单」第 3 项。

#### 0.9.6 第三轮自检（2026-09-24）：**速度主张必须收回**，并修正我自己的一处错误推理

> 前两轮审计比对范式与代码。第三轮去测**被声称的速度**——结果推翻了规范里两条硬门。

**发现 D（致命）：`50×` 与 `10 ms` 两条速度门都不成立，且原因不是调参。**

实测（`--decode exact|band`，TS0，1,288 条，batch 1，MIG 1g.5gb）：

| 长度桶 | decode(exact) | decode(band=128) |
|---|---|---|
| <100 | 44.8 ms | 46.4 ms |
| 100–200 | 134.7 ms | 138.7 ms |
| 200–400 | 639.4 ms | 659.2 ms |
| 400–600 | 1662.5 ms | 1603.2 ms |

两条结构性结论：

1. **带状化几乎不加速（400–600 桶仅 3.6%）**。本实现用的是「以 j 的配对者为轴」的递推，
   带状化只把每区间候选 `k` 限到 ≤ band 个 → 总量 `O(L²·band/2)`，而精确是 `O(L³/6)`；
   L=500/band=128 时运算量只差 **1.3×**。教科书里的 `O(L·band²)` 来自**另一种递推形式**。
   而且真正的成本是 Python 对 `O(L²)` 个区间的循环开销，带状化并不减少区间数。
   → **§5.0.1 里「带状/近线性解码」的表述必须改掉或明确标注为需要重构递推。**
2. **决策头省掉的是「配分函数」，不是「DP」**。校准的传统代价是配分函数（`O(L³)` + 指数/对数、
   常数很大）；我们把它换成 **1 次前向**（`O(L²d)`，GPU 并行）+ **1 次 max-product DP**
   （最坏仍是 `O(L³)`）。**渐近意义上并没有省掉 DP。**
3. **墙钟上我们更慢**：L≈500 时 System-1 ≈ 1.2 s 解码 + 0.37 s 前向，而 ViennaRNA 的 BPP 是 **C 代码**、
   量级几十 ms。差距来自**实现语言**，不是算法。

**处置**：

- **作废 §8.3 S1「≥50×」与 S3「L=512 ≤ 10 ms」**（保留编号，内容标注为已作废）。
- 论文只允许写：**「不必求配分函数即可给出校准概率」**——这**正是 C1 的实质**（配分函数是校准的传统代价），
  并如实报告解码墙钟与"需要编译实现"这一前置条件。
- 速度收益的正确表述：**常数因子级别**（去掉指数/对数、GPU 并行、无 `O(L³)` 配分函数），**非渐近级别**。
- 已完成的改进（可写进论文）：`_max_dp` 内层对 `i` 的向量化，Python 迭代 `O(L²)→O(L)`，
  实测 **3.0–4.1×**（L=100: 64.3→16.2 ms；L=300: 1009.6→245.3 ms；L=500: 1952.1→1055.5 ms），
  并对 `N`/`dec`/`kp` **三张表逐位等价**（25 项测试；含 tie、NaN/±inf、任意 mask、`min_loop` 变体）。

**发现 E（自我修正）：我在 §0.9.5 发现 C 里关于 `grad_clip` 的推理是错的。**

原话：「`grad_clip=1.0` 而裁剪前范数 40–673 → **每步都被裁死**，有效步长波动」。
**该推理不成立**：`clip_grad_norm_` 是**全局等比缩放**（所有参数乘同一常数 `c`），
而 AdamW 的 `θ ← θ − lr·m/(√v+ε)` 中 `m ∝ c·g`、`v ∝ c²·g²`，故 `m/√v` **与 c 无关**
→ **等比裁剪对 AdamW 近似是空操作**。残余效应只有 `c_t` 逐步变化给动量 EMA 引入的噪声。

**处置**：**T-A4 从"影响所有后续训练"降级为可选项**。仍然成立的部分：损失按配对数求和，
**不可跨步/跨臂比较**（这条是对的，只是它的后果比原先写的轻得多）。

**本节的两条修正都不削弱 C1**（卖点是校准），但**必须删掉一切「快 50×/10 ms」表述**——
否则审稿人一击即穿，而这类过度声明会连带损害真正站得住的那部分。

## 5. 模型架构编排（针对科学问题定制，公式与张量级）

> 原则：每个模块必须能回答"它对应哪个世界的哪条约束、解决哪个科学问题"。**禁止无依据的模块堆叠。**

### 5.0 统一数学框架：非交叉结构空间上的 Gibbs 分布

**这是整个架构的数学地基，也是"不是模块堆砌"的证明。**

记序列 `x = (x_1..x_L)`，`x_i ∈ {A,C,G,U}`。二级结构是一个**非交叉部分匹配**：

```
E(x) = { (i,j) : 1 ≤ i < j ≤ L,  j - i > 3,  x_i x_j ∈ 𝒫 }
M ⊆ E(x),   𝒫 = {AU, UA, GC, CG, GU, UG}
```

`j - i > 3` 是最小发夹环 steric 约束。非交叉条件：

```
∀(i,j),(k,l) ∈ M :  ¬( i < k < j < l ) ∧ ¬( k < i < l < j )
```

即 `M` 是 `{1..L}` 上的 outerplanar（非交叉）部分匹配。

**模型在结构空间上定义 Boltzmann / Gibbs 分布：**

```
P(M | x) = (1 / Z(x)) · exp( Σ_{(i,j) ∈ M} s_ij(x) )
Z(x)     = Σ_{M ∈ ℳ(x)} exp( Σ_{(i,j) ∈ M} s_ij(x) )
```

`s_ij(x) ∈ R ∪ {-∞}` 为决策头输出的配对得分，`ℳ(x)` 为全部合法结构。

**三个关键性质构成本方案的全部优势来源：**

| 性质 | 数学事实 | 工程后果 | 对应 Jev |
|---|---|---|---|
| `Z(x)` 可精确计算 | Nussinov 型 sum-product（inside），`O(L³)` | 可算**精确似然**，无需采样 / ELBO | — |
| 边际可精确计算 | inside-outside 给出 `p̂_ij = P((i,j) ∈ M)`，`O(L³)` | **校准置信度 = 精确边际概率** | J4 |
| MAP 可精确求解 | Nussinov max-product DP | 输出**必然合法**，非法结构率恒为 0 | J3 |

**该框架的谱系（已按 §0.7 问题 2 修正）**：ViennaRNA 的 McCaskill 算法用**固定 Turner 参数**算 `Z` 与配对概率；**CONTRAfold（Do et al. 2006）与后续 CRF 工作已用学习的线性打分函数替换固定参数，并用条件似然训练**——其梯度即 `(y-p̂)·∇s`，`p̂` 即 inside-outside 边际。**这些不是本方案的创新。**

> **本方案的定位**：在该谱系上做两件事——① 把线性打分函数换成**上下文相关的神经打分函数**；② **把"推理期免 DP 的校准"作为真正的目标**（§5.0.1），而非仅把 DP 当训练工具。

### 5.0.1 核心设计：双模式折叠（解决 §0.7 问题 1 的致命矛盾）

**问题重述**：若推理时仍需 inside-outside 求精确边际，代价 `O(L²d) + O(L³)` **慢于** McCaskill 的 `O(L³)`——速度主张崩塌。

**解法**：把"精确边际"从**推理时依赖**改为**训练时教师**。

```
┌──────────────────────────────────────────────────────────────┐
│ 训练期（可负担 O(L³)）                                         │
│   教师：inside-outside 精确边际 p̂^exact_ij  +  热力学教师        │
│   学生：决策头  →  p̂^head_ij                                   │
│   损失：L_NLL + λ_distill·L_distill + λ_RLCD·L_RLCD            │
│         └─ 把"精确边际"与"校准"同时蒸进头里                      │
└──────────────────────────────────────────────────────────────┘
                          ↓  蒸馏完成
┌──────────────────────────────────────────────────────────────┐
│ 推理期 System-1 快速模式（不跑配分函数）                         │
│   1× 前向 → p̂^head_ij（已校准）                                 │
│   带状/线性 DP O(L·B²) → 合法结构 M*                            │
│   总代价 ≈ O(L²d) + O(L·B²)   ← 相对 O(L³) 的加速来源            │
└──────────────────────────────────────────────────────────────┘
                          ↓  置信度门控
┌──────────────────────────────────────────────────────────────┐
│ 推理期 System-2 精确模式（按需）                                 │
│   对低置信区域调用 inside-outside / 热力学求解器                   │
│   仅在这些区域付出 O(·³) 代价                                    │
└──────────────────────────────────────────────────────────────┘
```

**三个关键点：**

1. **免 DP 是核心主张**：System-1 模式下**不计算配分函数**。这正是相对 McCaskill 的加速来源，也是 C1 的内容。
2. **RLCD 是承重结构**：既然不跑配分函数，`p̂^head` 的校准**不可能**来自精确边际——**只能来自训练**。故 §5.8 的 RLCD 是使速度主张成立的**必要条件**，不是装饰。
3. **精确边际的新角色**：训练期作为**蒸馏教师**（把 CRF 的精确概率蒸进免 DP 的头）。既保留 §5.0 框架的理论价值，又不让它在推理期成为瓶颈。

**由此得到的可检验命题（替代原 H2）：**

> 免 DP 的决策头，其配对概率的校准质量（ECE）与后验对数似然，能否达到**精确配分函数边际**的水平？若能，则 `O(L³)` 配分函数在**推理期**可被完全省去。

这是一个**清晰、可证伪、且对领域有实际意义**的命题——若成立，它改变的是 RNA 折叠的**推理成本结构**，而非仅仅提升一个 F1 数字。

### 5.0.2 核心架构：层级决策级联（解决 §0.7 问题 7 的 `O(L²)` 瓶颈）

> 这是本方案的**核心架构创新**。它把「决策数量」从 `O(L²)` 个碱基对降到 `O(L)` 个螺旋级决策 + 局部细化——**架构性的复杂度改进，而非带状化这种工程 hack**。

#### (a) 数学依据：层级分解是结构空间的固有性质，不是先验假设

非交叉部分匹配 `M` 的**弧图是一棵森林**：配对弧之间要么嵌套、要么并列，绝不交叉。而 **Nussinov DP 的递推本身就是这棵森林的树分解**。

> **关键论断**：层级分解**不是我们强加的归纳偏置**，而是非交叉结构空间 `ℳ(x)` 的**固有结构**。学习这个层级 = 学习 DP 的决策点。

#### (b) 物理依据：RNA 结构本身就是层级的

结构域 → 螺旋（helix）→ 碱基对。螺旋是**进化保守的功能单元**（堆叠配对段），而碱基级的配对模式在家族间漂移更大。**故在螺旋级做决策比在碱基级做决策更可迁移**——这直接服务于泛化（§0.8 问题 8）。

#### (c) 三级决策级联

| 级 | 决策单元 | 数量级 | 输出 | 计算 |
|---|---|---|---|---|
| **L0 粗粒度** | 块对 `(b₁, b₂)`（块大小 `w`） | `O((L/w)²)`，**稀疏化后 `O(L/w)`** | 该块对是否含螺旋 + 螺旋强度 | 低分辨率打分 |
| **L1 螺旋级** | 候选螺旋（连续堆叠配对段） | `O(L/w)` | 螺旋起止 + 置信度 | 中等分辨率 |
| **L2 碱基级** | 活跃螺旋内的具体配对 | `O(L)`（**仅活跃螺旋内**） | `p̂_ij` + 配对类型 | `O(w²)` 局部细化 |

**为什么这是复杂度改进**：真实 RNA 的配对数 ≈ `0.3L`，而**螺旋数 ≈ `0.05L`**。故结构在**螺旋尺度上是 `O(L)` 而非 `O(L²)`**：

```
总代价 ≈ O(L·d)  +  O(L·w²)        ← 层级级联
对比    O(L²·d)                     ← 扁平 L×L 头
对比    O(L·B·d)（牺牲长程）         ← 带状化 hack
```

#### (d) 与带状化的**本质区别**（必须写进论文）

| 方案 | 长程配对 | 复杂度 | 性质 |
|---|---|---|---|
| 带状化（banded） | ❌ **牺牲长程配对** | `O(L·B²)` | 工程 hack，丢掉 RNA 最需要的信号 |
| **层级级联** | ✅ **保留长程配对** | `O(L·w²)` | 架构改进：粗粒度块对**可覆盖任意距离**，只是"先粗后细" |

#### (e) 与校准 / 计算自适应的耦合

- L0 的不确定度直接决定是否细化到 L1/L2 → **计算量与结构复杂度成正比，而非与长度平方成正比**
- L0/L1 的不确定度决定是否升级到 System-2 精确物理 → 三级门控

#### (f) 风险与对冲（必须诚实报告）

| 风险 | 后果 | 对冲 |
|---|---|---|
| **L0 漏检螺旋（假阴性）** | 后续级别无法挽回 | **必须报告 L0 召回率**；设保守阈值（宁可多检不可漏检）；**L0 召回率作为独立门限** |
| 螺旋边界定义敏感 | 性能波动 | 螺旋边界作为超参扫描 |
| 短链上层级开销无收益 | 短链变慢 | 按长度自适应选择层级或扁平路径 |

**对冲方案**：**保留扁平 `L×L` 头作为可选路径**，消融对比「层级级联 vs 扁平头」的精度-复杂度权衡。若层级级联在短链上无优势，则按长度分派。

### 5.3 模块 A：序列编码器

#### 5.3.1 碱基理化嵌入（物理世界）

不用纯 one-hot。对每个碱基定义化学特征向量 `φ(x_i) ∈ R^{d_φ}`：

| 特征 | A | C | G | U | 物理含义 |
|---|---|---|---|---|---|
| 氢键供体数 | 1 | 1 | 2 | 1 | 配对化学 |
| 氢键受体数 | 1 | 2 | 1 | 2 | 配对化学 |
| 嘌呤/嘧啶 | R | Y | R | Y | 几何尺寸 |
| 环数 | 2 | 1 | 2 | 1 | 平面性 |
| 堆叠倾向 | — | — | — | — | 由 Turner 参数导出 |

```
h_i^(0) = W_e φ(x_i) + W_p p_i + v · u_i
```

- `W_e ∈ R^{d × d_φ}`，`W_p ∈ R^{d × d_pos}`
- `u_i`：可选 SHAPE/DMS 反应性标量；`v ∈ R^d` 为通道投影，`u_i = 0` 表示该位点无探测数据

#### 5.3.2 编码器堆叠

Pre-norm Transformer，`n_layer` 层；Q/K 使用 **RoPE 相对位置旋转**（配对强度是相对距离的函数）：

```
q_i = R(Θ, i) W_Q h_i ,   k_j = R(Θ, j) W_K h_j
R(Θ, i) = blockdiag_{m=1..d/2} [ cos(iθ_m)  -sin(iθ_m) ;
                                sin(iθ_m)   cos(iθ_m) ]
```

输出 `H = (h_1..h_L) ∈ R^{L×d}`。

**长链稀疏化**：注意力限制在 `|i-j| ≤ W` 带内 + `n_g` 个全局 token（如每 128 位取 1 个），复杂度降至 `O(L·W·d)`。

### 5.4 模块 B：约束决策头（核心创新，对应 Jev 的 decision head）

#### 5.4.1 候选空间与硬掩码（数学 + 物理）

```
Valid(i,j) = 1[ j - i > 3 ] · 1[ x_i x_j ∈ 𝒫 ]
s_ij ← -∞   if ¬Valid(i,j)
```

`j - i > 3` 是最小发夹环 steric 硬约束（物理），`𝒫` 是允许配对集（化学）。

#### 5.4.2 Turner 能量残差注入（物理先验，非后处理）

Turner 最近邻模型给出堆叠自由能 `ΔG°37_NN(x_i, x_j, x_{i+1}, x_{j-1})`；`37°C` 时 `RT ≈ 0.616 kcal/mol`。物理先验得分即 Boltzmann 对数几率：

```
s_ij^phys = - ΔG°37_NN(x_i, x_j, x_{i+1}, x_{j-1}) / RT
```

**残差形式（关键设计）**——模型学的不是绝对得分，而是**相对物理先验的修正**：

```
s_ij = s_ij^phys + MLP_T(z_ij)
```

`MLP_T` **末层零初始化**，因此训练起点**精确等价于「Nussinov DP + Turner 堆叠能」**，随后学习上下文相关修正。

> **必须精确表述（§0.7 问题 3）**：该起点**不等价于 ViennaRNA / McCaskill 模型**。Nussinov DP 只含堆叠项，**不含**环熵、coaxial stacking、终端错配、多分支环等。论文与消融中须以「Nussinov + Turner 堆叠能」为对照基线，**不得**声称"起点 = ViennaRNA"。

收益：

- 冷启动不差于「Nussinov + Turner 堆叠能」这一基线，不被随机初始化拖垮
- 可解释性：`MLP_T(z_ij)` 的幅值直接量化"模型比该物理基线多知道什么"
- 消融干净：置零 `MLP_T` 即精确回退到该物理基线

#### 5.4.3 配对表示与构造性对称（数学世界）

配对存在性是对称的（`s_ij = s_ji`）。用**置换不变**的配对表示**构造**对称性，而非事后平均：

```
z_ij = W_s [ h_i + h_j ;  h_i ⊙ h_j ;  |h_i - h_j| ] ∈ R^{d_z}
s_ij = w_s^T z_ij + s_ij^phys
```

`h_i + h_j`、`h_i ⊙ h_j`、`|h_i - h_j|` 在 `i ↔ j` 交换下不变，故 **`s_ij = s_ji` 恒成立（精确，非近似）**。张量实现：由 `H` 一次算出 `L×L×d_z`，对称性由构造保证，无需显式对称化算子。

配对**类型**有方向（`AU ≠ UA`），由独立的有序头给出：

```
t_ij = W_t [ h_i ; h_j ] ∈ R^6 ,   硬约束  t_ji = Π t_ij
```

`Π` 是固定的 6-类置换（`AU↔UA`、`GC↔CG`、`GU↔UG`）。构造性约束，非软惩罚。

#### 5.4.4 非交叉约束的落点（必须讲清的技术事实）

**非交叉是全局组合约束，无法用 `O(L²)` 的局部掩码精确表达。** 论文须诚实说明，并给出分层方案：

| 约束类型 | 作用范围 | 实现层 | 复杂度 |
|---|---|---|---|
| 最小发夹环、允许配对集 | 局部（单配对） | §5.4.1 硬掩码 | `O(L²)` |
| 配对类型方向性 | 局部（单配对） | §5.4.3 置换约束 | `O(L²)` |
| **非交叉** | **全局（配对间耦合）** | **§5.5 inside-outside / Nussinov DP** | `O(L³)` |

**训练**时非交叉经可微 DP（§5.5.2）进入梯度；**推理**时经 Nussinov MAP（§5.5.1）精确保证。因此"约束内建"是**在 DP 层内建**，而非在注意力里伪造一个不精确的掩码。

> 备选（若审稿人要求显式配对间注意力）：配对槽结构化注意力
> `A[(i,j),(k,l)] = -∞  if cross((i,j),(k,l))`，复杂度 `O(L⁴)`，
> 仅在 top-k 候选配对集（`k ≈ 16`）上可行。**列为消融项，不作主方案。**

### 5.5 模块 C：确定性求解 harness（System 2）

#### 5.5.1 Nussinov MAP（推理，精确）

```
N(i,j) = max( N(i, j-1),
              N(i+1, j),
              N(i+1, j-1) + s_ij,
              max_{ i < k < j-1 } [ N(i, k-1) + N(k+1, j-1) + s_kj ] )
N(i,j) = 0    for  j - i ≤ 3
```

`O(L³)` 时间、`O(L²)` 空间；traceback 给出 `M* = argmax_{M ∈ ℳ(x)} Σ_{(i,j) ∈ M} s_ij`。

**合法性保证**：`M*` 由 DP 构造，天然非交叉、满足最小发夹环、配对均在 `𝒫` 内 → **非法结构率恒为 0**。直接对应 Jev 的 J3（类型安全 / 零格式幻觉）。

#### 5.5.2 可微 DP（训练，端到端）

`max` 不可微。**主方案：隐式微分（Danskin / 最优值函数次梯度）**。DP 是分段线性 `max`，其最优值 `N(1,L)` 对 `s_ij` 的次梯度恰为最优解的指示函数：

```
∂ N(1,L) / ∂ s_ij = 1[ (i,j) ∈ M* ]
```

这正是结构化 SVM 式梯度。实现：`torch.autograd.Function` 自定义前向（DP 求 `M*`）与反向（把上游梯度散布到 `M*` 的配对上），`O(L³)` 前向 + `O(|M*|)` 反向，**无需对 DP 计算图求导**。

**备选：soft-Nussinov（log-sum-exp 平滑）**

```
Ñ(i,j) = τ · log Σ_{分支} exp( Ñ(·) / τ )      τ → 0 时收敛到 max
```

梯度更平滑，但需保存整个 `O(L³)` DP 图，显存昂贵；仅在 `L ≤ 256` 时作对照。

**必须显式排除的反例**：Sinkhorn / 最优传输松弛**不能**用于本问题——它求解的是一般匹配（允许交叉），无法表达非交叉约束。论文中须显式说明该路线不适用。

#### 5.5.3 训练目标：精确似然

由 §5.0 的 Gibbs 分布，正确结构 `M_gt` 的负对数似然：

```
L_NLL = - log P(M_gt | x) = log Z(x) - Σ_{(i,j) ∈ M_gt} s_ij(x)
```

梯度：

```
∂ L_NLL / ∂ s_ij = ∂ log Z(x) / ∂ s_ij  -  y_ij  =  p̂_ij - y_ij
                 ⟹  ∇_θ L_NLL = Σ_{(i,j)} ( p̂_ij - y_ij ) · ∇_θ s_ij
```

> **符号勘误（实现阶段由数值验证发现并修正）**：本 spec 早期版本写作 `(y - p̂)·∇s`，**符号写反了**。
> 正确推导：`∂log Z/∂s_ij = E[1{(i,j) ∈ M}] = p̂_ij`，故 `∂L_NLL/∂s_ij = p̂_ij - y_ij`。
> 该式已由有限差分与暴力枚举独立验证（`logZ` 误差 2.2e-16、`p̂` 误差 5.6e-17、梯度逐元素一致）。

**这个梯度形如 `(p̂ - y) · ∇s`**——与 logistic 回归梯度同形（差一个整体符号，因我们优化 NLL 而非似然），但 `p̂` 是**受非交叉约束的精确边际**，而非独立 sigmoid。故本模型可一句话描述为：

> **带非交叉结构约束的 logistic 回归。**

这同时解释了为何校准天然成立（`p̂` 本就是概率模型的边际）。`Z(x)` 与 `p̂_ij` 均由 inside-outside 算法 `O(L³)` 精确算出。

**实现约定（`src/rnajepa/harness.py`）**：`scores` 只读取**严格上三角**（`i < j`），因此梯度也只写入上三角，下三角为 0。若把对称的 `p̂` 填满两个三角，方向导数会被重复计算——这是实现期实际发现并修正的一个 bug。

#### 5.5.4 低置信回退（真实世界，对应 Jev 的 J5）

边际 `p̂_ij` 即校准置信度。门控：

```
α_ij        = σ( (p̂_ij - τ) / γ )                       # 软门控
s_ij^final  = α_ij · s_ij + (1 - α_ij) · s_ij^thermo
```

低置信配对被 ViennaRNA / RNAstructure 重新打分，并记录**回退比例**纳入报告。对应 Jev 的"低置信转交更慢的推理模型"。

### 5.6 决策顺序（**已降级为消融项**，见 §0.7 问题 4）

> **诚实声明**：本节**不是创新点**。原稿曾把「共转录顺序 = Nussinov 填表顺序」当作贡献，但审稿人视角下它只是**重新表述** DP 的固有顺序，**不改变分布、不带来新能力**。因此降级为消融项。

**背景**：真实 RNA 在转录中 5'→3' 逐步折叠，5' 区域先于 3' 区域形成结构。

**与 DP 的关系**：Nussinov 递推本身即从左到右填表，`N(i,j)` 只依赖 `·' < j` 的子问题。故共转录顺序**恰好等于** DP 的填表顺序——这是一个**观察**，而非设计创新。

**保留为消融项的理由**：既然顺序与 DP 一致，就值得检验"换成其他顺序是否变差"。三种顺序：

| 顺序 | 定义 |
|---|---|
| 共转录 | 5'→3'，即碱基 `k = 1..L` 依次决策（= Nussinov 填表顺序） |
| 对角 | 按配对跨度 `j-i` 递增 |
| 随机 | 随机置换 |

**预期（H4，已降级）**：影响**有限**。若确认无显著差异，**作为负结果报告**，不强行解释。

> **若要做成真创新**，需实现**流式增量折叠**（每新增一个碱基 `O(1)` 更新概率矩阵，支持边转录边预测）。这是一个**独立且更有价值**的问题，但**本工作不做**，仅在前景中提及。

### 5.7 模块 D：热力学决策蒸馏预训练（纯血 Jev 的 System-1/System-2 分工）

**这是本方案替代 JEPA 的预训练方式，也是 Jev 范式最核心的迁移点。**

Jev 的架构哲学是：**用快的 System-1 承接慢的 System-2 的高频决策**。对应到 RNA：

| 角色 | 本方案中的具体对象 | 特性 |
|---|---|---|
| **System 2（教师）** | ViennaRNA McCaskill 配分函数 / RNAstructure / LinearPartition | 慢（`O(L³)` 大常数），但物理准确、给出**校准配对概率** |
| **System 1（学生）** | §5.4 决策头 | 快（**单次前向**），学习教师的校准概率 |

**蒸馏目标**：学生匹配教师的**校准概率矩阵**（软标签），而非硬结构：

```
L_distill = Σ_{ i<j } D( p_ij^teacher  ‖  p̂_ij )
```

- `D` 取 KL 或 L2（作为消融项）
- `p_ij^teacher` 为教师配分函数的精确配对概率（**本身即校准量**）
- 教师集成：`p^teacher = mean(p^{ViennaRNA}, p^{RNAstructure}, p^{LinearPartition})`，学生学**集成教师的共识**，从而学到超越单一物理参数集的修正

**规模来源（解决"无结构标签"问题）**：对已落盘的 20 GB / ~36M 条无标签 mRNA 语料，用教师批量生成软标签，即得**大规模决策语料**。这完全在 Jev 范式内（决策 + 校准概率），且不需要结构标注。

**与硬标签监督的联合**：

```
L = L_NLL(硬标签, 来自 bpRNA-1m 等)  +  λ_distill · L_distill(软标签, 来自教师)
```

**为什么这比 JEPA 更契合本任务（须写进论文）**：

1. 蒸馏目标**不会饱和**——教师概率矩阵是连续、高熵的目标，不存在"区域均值"式的线性可解坍缩
2. 蒸馏**直接对齐决策空间**，与最终任务（配对决策）同构，而非在对齐一个间接的隐空间摘要
3. 蒸馏把 System-2 的**准确**与 System-1 的**快**解耦，天然支撑 §7 的速度-精度 Pareto 主张
4. 蒸馏目标**可校准**——教师概率本身校准，学生学的是校准量

### 5.8 模块 E：RLCD-RNA（面向校准配对决策的强化学习，对应 J9）

> **这是本方案对 Jev 范式最核心的迁移，也是最容易被漏掉的一环。**
> 只搬「单次前向 + 受限空间」只得到 Jev 的一半；Jev 的置信度之所以可信，是因为 **RLCD 显式训练了概率校准**。

#### 5.8.1 为什么需要 RLCD：似然训练不保证校准

`L_NLL`（§5.5.3）优化的是**似然**，而似然最优**不蕴含**概率校准。具体到本任务，`L_NLL` 的梯度 `(y - p̂)·∇s` 会推动 `p̂` 逼近 `y`，但在下列情形会产生系统性失准：

- 训练集与测试集的**家族分布漂移**（bpRNA-new 场景）
- 结构标签本身的**噪声**（PDB 分辨率、探测数据误差）
- **长链**上的误差累积

结果是：`p̂_ij = 0.9` 的位置，实际配对频率可能只有 0.6——**置信度不可用**，J5 的置信度门控随之失效。

**RLCD 的目标（Jev 原话的等价表述）**：

> **当模型说 80% 的时候，现实中应当真的大约 80% 正确。**

#### 5.8.2 RLCD-RNA 的形式化

**决策单元**：每个候选配对 `(i,j)` 是一个二元决策
```
a_ij ∈ {0, 1}      （是否配对）
p̂_ij = P(a_ij = 1 | x)      （模型给出的决策概率）
```

**奖励：恰当评分规则（proper scoring rule）**

采用 Brier 分数作为奖励（恰当评分规则保证最优策略是报告真实概率）：
```
R_ij = 1 - ( a_ij - p̂_ij )²        （Brier 奖励，值域 [0,1]）
```
或对数评分：`R_ij = a_ij log p̂_ij + (1-a_ij) log(1-p̂_ij)`

**校准误差惩罚（直接对齐 Jev 的判据）**

把 ECE 写成可微分形式（软分箱 / 核密度 ECE）：
```
ECE_soft = Σ_{b=1}^{B}  (n_b / N) · | mean(p̂ ∈ bin b) - mean(a ∈ bin b) |
```

**RLCD 总目标**：
```
L_RLCD = - E[ R ]  +  β · ECE_soft
```

**优化**：策略梯度（REINFORCE）或直接可微优化。

> **本方案的关键优势（须在论文中强调，但表述必须精确）**
>
> 因为 Gibbs 框架给出**精确边际** `p̂_ij`，校准目标**不需要蒙特卡洛采样估计概率**——这是相对通用 LLM 上 RLCD 的真实优势。
>
> **但表述必须精确（实现阶段由子代理发现并修正）**：该"无采样"性质成立于**概率空间**——即 `∂L_RLCD/∂p̂_ij` 可由 `inside_outside` 直接给出。若要把它反传到**原始得分** `s_ij`，需要 `∂p̂_ij/∂s_kl`，即 `log Z` 的 Hessian（朴素计算 `O(L⁴)`）。
>
> **这不构成问题，因为我们根本不需要该路径**：
>
> | 角色 | 概率来源 | 是否需要 `∂p̂/∂s` |
> |---|---|---|
> | **System-1 学生**（RLCD 作用于它） | 决策头的**直接概率输出** + 温度缩放 | ❌ 不需要——`∂p̂/∂θ` 就是头的 Jacobian，廉价 |
> | **精确边际** | `inside_outside` | ❌ 不需要——它只作 **detached 教师**，不参与反传 |
>
> 因此论文中的正确表述是：**RLCD 作用于 System-1 头的直接概率输出；精确边际仅作为无梯度的蒸馏教师**。不得声称"可以廉价地反传穿过配分函数"。

#### 5.8.3 与似然目标的关系

```
L = L_NLL  +  λ_distill · L_distill  +  λ_RLCD · L_RLCD  +  λ_1 · L_cal
```

四项各司其职：

| 项 | 作用 | 优化对象 |
|---|---|---|
| `L_NLL` | 学**结构**（硬标签） | 判别力 |
| `L_distill` | 学**物理教师的概率**（软标签） | 知识迁移 |
| `L_RLCD` | 学**概率校准** | 置信度可信性（J4/J5） |
| `L_cal` | 事后温度缩放 | 校准的后处理修正 |

#### 5.8.4 诚实标注要求

**RLCD 的具体算法未公开**（§0.3）。因此：

- 论文中必须标注本目标为 **"RLCD 启发式（RLCD-inspired）的自设计目标"**，不得声称复现了 Jev 的 RLCD
- 不得声称与 Jev 的 RLCD 等价或更优
- 须明确列出本文采用的是 Brier / 对数评分 + 软 ECE 惩罚这一**自选组合**，并说明选择理由

### 5.9 长链与复杂度（SQ2 的核心论证）

| 路线 | 前向次数 | 复杂度 | 瓶颈 |
|---|---|---|---|
| 自回归结构 LM | `O(L)` | `O(L·d²)` | 逐 token 解码 |
| E2Efold（展开 K 步 DP） | `K×` | `O(K·L³)` | DP 展开 |
| **McCaskill 配分函数（System 2 教师）** | — | `O(L³)`，**常数大** | 需要完整 DP 才给出概率 |
| **本方案（System 1 决策 + DP harness）** | **`1×`** | `O(L²·d)` 得分 + `O(L³)` DP | 得分矩阵的 `O(L²)` |
| LinearFold | — | `O(L)` | 纯 DP，精度受限 |

带窗稀疏化：限制 `|j - i| ≤ B` → 得分矩阵 `O(L·B·d)`、DP `O(L·B²)`。

**关键诚实点（必须写进论文）**：本方案在**算法复杂度上不必然优于 LinearFold 的 `O(L)`**。取胜路径有三条，须在论文中分清并分别给出证据：

1. **对 System-2 的加速（最强主张）**：单次前向替代 McCaskill 的 `O(L³)` 大常数计算，目标 ≥ 50× 加速，且概率质量相当；
2. **精度取胜**：在 LinearFold 精度不足的场景（假结、长链、非经典配对）上以可接受延迟取得更高 F1；
3. **GPU 并行取胜**：得分矩阵高度可并行，而 DP 是串行递推。

### 9.2 叙事定位（一句话与四段式，已按 §0.7 重构）

**一句话**：

> **RNA 二级结构预测的瓶颈不是表征能力，而是"信任"与"成本"的两难**——物理方法给出校准概率却要付 `O(L³)` 配分函数，深度方法便宜却输出未校准、不合法、跨家族泛化差。我们证明：**单次前向的决策头可以被训练得与精确配分函数边际同等校准**，从而在推理期**完全省去配分函数**；而由此得到的校准置信度进一步支撑**计算自适应折叠**——只在不确定的地方调用精确物理。

**四段式叙事**：

1. **问题（信任与成本的两难）**：现有方法或"准但慢"（McCaskill/CONTRAfold，`O(L³)` 才有概率），或"快但不可信"（UFold/SPOT-RNA 的 sigmoid 未校准、需启发式后处理才能合法、跨家族泛化差）。**没人回答"这个预测能不能信"**，也没人回答"何时值得花 `O(L³)`"。
2. **方法（免 DP 的校准决策头，C1）**：把精确配分函数边际作为**训练期教师**（而非推理期依赖）蒸进单次前向的头，并用 RLCD 式目标**显式优化校准**。关键洞见：**精确边际使校准目标可精确求梯度、无需采样估计**。结果：推理期不跑配分函数，概率仍与精确边际同等校准。
3. **系统（计算自适应折叠，C2）**：校准置信度成为**计算分配的控制器**——低置信区域才升级到精确物理。这把"何时花 `O(L³)`"从工程启发式变成**模型可决策**的问题。
4. **测量（校准优先评测协议，C3）**：把 ECE / 可靠性图 / 边际校准 / 后验对数似然 / "合法化代价"引入本领域作为一等指标，填补领域评测缺口。

**谱系诚实性**：论文须明确说明本工作**站在 CONTRAfold / CRF 谱系上**，贡献在于"免 DP 的校准"与"计算自适应"，**而非**首创配分函数框架。

**必须在论文中明确承认的五点局限**：
- Jev **无同行评审论文**，其性能数字为厂商自测，本工作只引用其范式主张
- **Jev 的 RLCD 算法未公开**，本文的校准目标为"RLCD 启发式自设计"，不得声称复现或等价
- **Gibbs / 配分函数框架非本文首创**，属 CONTRAfold / CRF 谱系（§0.7 问题 2）
- 本方案**算法复杂度不必然优于 LinearFold 的 `O(L)`**
- 涉及 `dev == test` 的既有迁移任务，其结论存在该缺陷

- **THEN** 恰好 1 次前向产出 `L×L` 对称得分矩阵，对称性误差 = 0，无自回归解码步骤

### Requirement: 物理先验注入
系统 SHALL 以 `s_ij^phys = -ΔG°37_NN/RT` 构成物理先验，SHALL 以残差形式 `s_ij = s_ij^phys + MLP_T(z_ij)` 注入，且 `MLP_T` SHALL 末层零初始化。

#### Scenario: 物理先验消融
- **WHEN** 将 `MLP_T` 置零
- **THEN** 输出精确等价于纯 Turner 模型（有数值验证）

### Requirement: 热力学决策蒸馏预训练
系统 SHALL 以热力学配分函数（ViennaRNA / RNAstructure / LinearPartition，版本锁定）为 System-2 教师，SHALL 以决策头为 System-1 学生，SHALL 以 `L_distill = Σ D(p^teacher_ij ‖ p̂_ij)` 蒸馏**校准概率矩阵**（软标签），SHALL 与硬标签的 `L_NLL` 联合训练。

#### Scenario: 蒸馏目标健康性
- **WHEN** 蒸馏训练进行
- **THEN** 目标不出现早期饱和（须有与 JEPA 区域均值目标对照的饱和诊断记录）

#### Scenario: 教师版本锁定
- **WHEN** 生成教师软标签
- **THEN** 教师软件版本与 Turner 参数版本被记录并锁定，保证软标签可复现

### Requirement: RLCD-RNA 校准决策训练
系统 SHALL 提供面向校准配对决策的强化学习目标（RLCD 启发式）：以恰当评分规则（Brier 或对数评分）为奖励，SHALL 以可微软 ECE 为校准惩罚，SHALL 利用 Gibbs 框架的精确边际 `p̂_ij` 计算校准梯度而**无需蒙特卡洛采样估计**。

#### Scenario: 校准可精确优化
- **WHEN** 反传 RLCD 目标
- **THEN** 校准梯度由精确边际 `p̂_ij` 直接给出，不依赖采样估计

#### Scenario: 诚实标注
- **WHEN** 论文描述 RLCD 部分
- **THEN** 必须标注为"RLCD 启发式自设计目标"，并说明 Jev 的 RLCD 算法未公开、本文不得声称复现或等价

#### Scenario: 校准非装饰
- **WHEN** 报告 RLCD 收益
- **THEN** 须同时报告 ECE 改善与 bpRNA-new F1 变化，以检验校准是否真正转化为泛化收益

### Requirement: 确定性求解 harness
系统 SHALL 用 Nussinov max-product DP 求合法最大权非交叉匹配作为推理输出，SHALL 保证输出 100% 合法；SHALL 提供带窗稀疏化；SHALL 用隐式微分实现可微 DP。

#### Scenario: 合法性保证
- **WHEN** 对任意得分矩阵执行 harness
- **THEN** 非法结构率 = 0，最小发夹环违规率 = 0

#### Scenario: 显式排除不适用的松弛路线
- **WHEN** 文档化可微 DP 可选方案
- **THEN** 显式说明 Sinkhorn / 最优传输不适用于非交叉约束

### Requirement: 共转录因果决策顺序
系统 SHALL 支持按 5'→3' 共转录顺序决策，SHALL 提供对角顺序与随机顺序作为对照。

#### Scenario: 顺序对照实验
- **WHEN** 在相同编码器与数据下切换三种顺序
- **THEN** 输出各顺序在分长度桶上的 F1 曲线，用于检验 H4

### Requirement: 校准置信度
系统 SHALL 以 inside-outside 精确边际 `p̂_ij` 作为置信度，SHALL 支持按长度桶的温度缩放，SHALL 报告 ECE、可靠性图与边际校准。

#### Scenario: 置信度门控
- **WHEN** 置信度低于阈值
- **THEN** 交由热力学求解器重打分，并记录回退比例

### Requirement: 量化成功标准
系统 SHALL 在基线复现完成后复核并冻结 §8 的门限，SHALL 在投稿前逐项核验硬门 G1–G5。

#### Scenario: 门限未达成
- **WHEN** 任一硬门未达成
- **THEN** 不得进入投稿流程

### Requirement: 测评协议与基线复现
系统 SHALL 在固定分析计划下评测全部基线，SHALL 用官方代码与官方权重并记录 commit hash 与权重哈希。

#### Scenario: 基线纳入
- **WHEN** 纳入任一对比模型
- **THEN** 记录仓库 commit、权重哈希、评测脚本版本，结果可被第三方复现

### Requirement: 速度基准
系统 SHALL 在同一硬件上测量延迟、吞吐与峰值显存，SHALL 按长度桶分别报告，SHALL 报告相对 McCaskill 配分函数的加速比。

#### Scenario: 速度对比
- **WHEN** 对比决策模型与 McCaskill / E2Efold / 自回归模型
- **THEN** 输出同硬件下的 latency-accuracy Pareto 曲线，而非单一数字

### Requirement: 消融完整性
系统 SHALL 完成 §7.5 列出的全部消融项。

#### Scenario: 消融缺失
- **WHEN** 任一消融项未完成
- **THEN** 论文不得声称对应机制的因果贡献

### Requirement: 论文产出与学术规范
系统 SHALL 保证每个强主张可回溯到论文行、证据或显式限制说明；SHALL NOT 编造 DOI、期刊等级、影响因子或全文发现。

#### Scenario: 引用核验
- **WHEN** 撰写任一引用
- **THEN** 须具备标题、作者/年份、标识符与 URL 方可标记已核验，否则标记待核验

# REMOVED Requirements

### Requirement: 隐空间预测性预训练（JEPA 式）
**Reason**：既有实验记录（`records/A3_latent_target_comparison.md`、`records/factor_probe_control_analysis.md`）给出三条否定性证据——区域均值摘要目标几乎立即饱和（cos 0.993 / L_JEPA 0.02–0.05）；因子探针的原始对照是空操作（学习基与随机基数值完全相同）；改用秩匹配随机子空间后学习因子相对随机子空间无优势。原假设 C3 不被证据支持。且用户明确要求聚焦纯血 Jev 架构。
**Migration**：由「热力学决策蒸馏预训练」（§5.7）替代。蒸馏直接对齐决策空间，目标不易饱和，且与 Jev 的 System-1/System-2 分工一致。

# 执行边界（硬约束）

**研究重心（已确认）**
- 以 **RNA 二级结构预测为主任务**，纯血 Jev 决策范式用于替代慢速求解与自回归解码
- **不引入 JEPA 线**（隐空间预测 / EMA teacher / 区域因子分解）
- 「替代 decoder 下词预测」**不作为独立研究线**
- 论文的唯一成功判据是**可发表**，不以"必须涨点"为前提；负结果 + 机制分析同样计入产出

**In-scope**
- RNA 二级结构（含假结）预测
- 决策模型架构设计与定制
- 热力学决策蒸馏预训练
- 数据获取、清洗与审计
- 测评、消融、速度基准
- 论文撰写与投稿

**Out-of-scope（明确不做）**
- JEPA / 隐空间预测性预训练
- RNA 三级结构从头预测（仅作补充对比引用）
- RNA 序列设计 / 生成式设计
- 湿实验验证
- 蛋白质结构预测
- 通用 LLM 训练
- 推翻或修改 `rna-jepa/` 的既有结论

**不可逾越的红线**
1. 测试集不参与任何超参选择
2. 所有基线使用官方代码 + 官方权重，记录 commit 与哈希
3. 所有数据剔除可追溯（原因码 + 衰减表）
4. 速度测量同硬件同协议
5. 教师模型版本与 Turner 参数版本锁定
6. 不编造任何引用、数字或结论
7. 负结果如实报告，不选择性汇报
8. 不把"计划中的数据"当作"已有数据"

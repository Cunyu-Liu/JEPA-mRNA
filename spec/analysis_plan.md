## 1. 假设（H1–H7，与 spec §1 逐字一致）

- **H1（已修正）**：在固定编码器与数据下，「DP 层内建约束」相对「无约束接触图 + 启发式后处理」，其**合法化所付出的 F1 代价**显著更低。
  > 原 H1「非法结构率 = 0」近乎同义反复（任何约束解码都能做到），已废弃。修正后测的是**代价**，有区分度。
- **H2（已修正，核心命题）**：**免 DP** 的决策头（System-1 模式，**不计算配分函数**）其配对概率校准（ECE）与后验对数似然**达到精确配分函数边际的水平**，同时延迟降低 ≥ 50×。
  > 原 H2 未说明"免 DP"，与精确边际要求冲突（见 §0.7 问题 1）。修正后命题清晰可证伪。
- **H3**：热力学决策蒸馏预训练，在低同源性测试集（bpRNA-new）上的 F1 显著优于无蒸馏训练。
- **H4（已降级）**：决策顺序（共转录 vs 对角 vs 随机）的影响**预期有限**——原假设"共转录顺序更优"缺乏机制依据（§0.7 问题 4）。**本项以消融形式如实报告，不预设方向**；若确认无差异，作为负结果报告。
- **H5**：在**匹配平均计算量**（而非匹配延迟）的条件下，置信度门控的混合范式 F1 高于纯决策模型与纯热力学模型。
  > 强化为"匹配计算量"，使 C2（计算自适应折叠）的主张可直接检验。
- **H6**：显式校准训练（RLCD 式）在相同架构与数据下，ECE 显著低于纯似然训练，且该改善**可转化为 bpRNA-new 上的 F1 增益**（即校准不是装饰，而是泛化收益）。
- **H7（新增，泛化，§0.8 问题 8）**：**层级决策级联**（螺旋级参数化）在 bpRNA-new（跨家族 OOD）上的 F1 **优于扁平 `L×L` 参数化**，且优势在长链上更大。
  > 机制假设：螺旋是进化保守的功能单元，螺旋级参数化比碱基级配对模式**更可迁移**。若被证伪，说明泛化瓶颈不在参数化层级，本身即为有价值的负结果。

> H1–H7 若被证伪，同样构成可发表结论（负结果 + 机制分析）。**不以"必须涨点"为设计前提。**

**假设与判据的对应**

| 假设 | 主要判据 | 关键消融 |
|---|---|---|
| H1 | 合法化 F1 代价（DP 内建 vs 无约束 + 后处理） | 去掉非交叉约束 |
| H2 | S7（System-1 ECE 与精确边际 ECE 之差 ≤ 0.02）+ S1 加速比 | 去掉 DP harness；System-1/2 切换 |
| H3 | bpRNA-new F1（蒸馏 on/off） | 去掉热力学决策蒸馏；KL vs L2；教师集成 vs 单一 |
| H4 | 分长度桶 F1 曲线（三种顺序），**不预设方向** | 决策顺序共转录 / 对角 / 随机 |
| H5 | S6（匹配平均 FLOPs 下门控升级最优） | 门控升级 vs 纯 System-1 vs 纯 System-2 |
| H6 | ECE 改善 **且** bpRNA-new F1 变化（联合报告） | 去掉 RLCD 校准目标；Brier vs 对数评分；`λ_RLCD`/`β` 扫描 |
| H7 | bpRNA-new F1（层级 vs 扁平），长链子集上优势更大 | 层级级联 vs 扁平 `L×L` 头 |

## 2. 七类指标（缺一不可，spec §7.1）

| # | 指标类 | 具体量 | 说明 |
|---|---|---|---|
| 1 | **配对层面** | Precision / Recall / F1（碱基对级）、MCC | 主报告指标 |
| 2 | **结构层面** | INF（Interaction Network Fidelity） | 结构整体保真度 |
| 3 | **校准** | ECE、可靠性图、NLL / Brier score；**边际校准**；真实结构在模型下的对数似然 | 因 `p̂_ij` 是精确边际，须额外报告边际校准与后验对数似然 |
| 4 | **合法性** | 非法结构率（目标 0）、最小发夹环违规率 | 架构硬保证 |
| 5 | **速度** | 单序列延迟（ms，**分长度桶**）、吞吐（seq/s）、峰值显存、GPU 小时/千条；**相对 McCaskill 配分函数的加速比** | 同硬件同协议 |
| 6 | **跨家族泛化** | bpRNA-new 上的 F1（**独立报告，与同源评测分列**） | 不可与同源结果合并 |
| 7 | **回退行为** | 低置信回退比例（spec §5.5.4）、回退对 F1 的边际贡献 | System-1 → System-2 的门控统计 |

**速度测量协议（固定）**：同硬件；含 warmup；batch=1 与 batch=32 **分列**；CUDA events 计时；报告均值与分位数；每个长度桶独立报告。

## 3. 统计方法（spec §7.4，硬要求）

1. **重复性**：每配置 **≥ 5 seed**，报告 **均值 ± std**。
2. **配对显著性检验**：
   - **Wilcoxon signed-rank**（配对、非参数；用于同数据同长度的配对比较）；
   - **bootstrap 置信区间**（≥ 10,000 次重采样；报告 95% CI）。
3. **多重比较校正**：**Holm-Bonferroni**（家族内控制 FWER）与 **FDR（Benjamini-Hochberg）** 两种均报告；正文以 Holm-Bonferroni 为主，FDR 作为稳健性附报。
4. **效应量**：报告均值差与相对变化幅度，不只报告 p 值。
5. **负结果**：p 值不显著时如实报告"无显著差异"，不得以事后子集挑选制造显著性（spec 红线 7）。

| 编号 | 指标 | 目标 |

### 4.3 速度门（核心主张，**仅适用于 System-1 免 DP 模式**）

> **前提（§0.7 问题 1）**：以下门限**只在 System-1 模式下成立**——该模式**不计算配分函数**。若误把 inside-outside 计入推理，总代价 `O(L²d)+O(L³)` 将**慢于** McCaskill，门限不成立。

| 编号 | 指标 | 目标 | 说明 |
|---|---|---|---|
| **S1** | 相对 McCaskill 配分函数加速（同硬件，`L=512`，**System-1 免 DP**） | **≥ 50×** | 加速来源 = 跳过 `O(L³)` 配分函数 |
| **S2** | 相对 E2Efold 加速（同硬件，`L=512`） | **≥ 5×** | 加速来源 = 1 次前向 vs 展开 K 步 DP |
| **S3** | 单序列延迟（`L=512`，GPU，batch=1，System-1） | **≤ 10 ms**（待基线标定后复核） | |
| **S4** | 长链可运行性（`L=2048`） | 可运行，且 F1 相对 `L≤512` 衰减 **≤ 15%** | |
| **S5** | 速度-精度 Pareto | 在同等精度下延迟最低（或同等延迟下精度最高） | |
| **S6** | **计算自适应收益** | 在**匹配平均 FLOPs** 下，门控升级的 F1 ≥ 纯 System-1 与纯 System-2（H5 / C2） | 计算自适应折叠的直接检验 |
| **S7** | **免 DP 的校准代价** | System-1 的 ECE 与**精确边际**的 ECE 之差 **≤ 0.02**（H2 / C1） | **C1 是否成立的判据** |
| **S8** | **层级级联的复杂度收益** | 在 `L ≥ 1024` 上，层级级联的**实测 FLOPs/延迟显著低于扁平 `L×L` 头**，且 F1 不劣于扁平头（H7 / C2） | **C2 是否成立的判据** |
| **S9** | **层级级联不牺牲长程配对** | 在含长程配对（跨度 > `L/2`）的测试子集上，层级级联的 F1 **不低于**扁平头；且**高于带状化基线** | 证明层级级联优于带状化 hack（§5.0.2(d)） |

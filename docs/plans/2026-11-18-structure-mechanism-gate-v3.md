# v3 结构学习机制创新裁决（2026-11-18）

## 裁决

**`STOP_NO_JUSTIFIED_NEW_MECHANISM`：当前不启动新的结构学习 pilot。**

这不是“结构模态普遍无效”的全称结论，而是对当前候选机制投入产出的审查：没有任何一个候选同时满足“相对现有宿主具有独立的新信息或新归纳偏置、可由现有标签检验、不是旧方法换包装”三项要求。没有满足条件的机制，就不为 GPU 占用、训练时长或预印本叙事启动实验。

## 为什么不能默认增加结构辅助目标就有创新

当前 H0 已包含直接的配对监督、ResNet2D、Turner stacking 和精确非交叉 DP。结构标签并不是只存在于新增 JEPA 中。新增辅助目标必须解释它提供了什么**独立于直接配对监督的新信息或新归纳偏置**，而不是仅把相同配对标签换种形式再使用一次。

当前可用监督仍主要是 canonical-nested 配对。它不能支持完整三维结构、复合物环境、普遍非 canonical 配对或假结理解的声明。扩大同源审计或 PDB 候选数量不能回答这个机制问题。

## 重新放行的必要条件

只有未来候选能够先给出以下全部内容，才允许设计新的 pilot：

1. **独立的数学命题**：明确新信息或新归纳偏置是什么，以及为什么它不等同于直接配对监督、Turner 或已有 JEPA。
2. **可证伪的主假设**：不是“辅助损失下降”或“工程可运行”，而是预先定义主任务效应及失败条件。
3. **标签范围匹配**：所需结构标签真实存在，来源、索引、质量、许可和下游隔离均通过；不得用 canonical-nested 代替三维或复合物标签。
4. **可识别的对照**：同初始化、同数据、同主损失、容量匹配、shuffle/random 和自然收敛比较；不得通过改变数据或预算制造表观提升。
5. **推理边界不变**：单 checkpoint、仅序列推理，原 ResNet2D、Turner 和精确 DP 的身份不得被替换或冒充。
6. **停止审计扩张**：完整预训练重叠不是同初始化 pilot 的前置；下游去重与标签 QA 仍必须通过。外部“未见/OOD”措辞继续受预训练暴露限制。

上述条件未同时满足时，维持停止，不先训练后找解释。

## 论文与后续工作定位

当前有两条诚实路径：

- **证据与评估报告**：保留数据质量、严格对照、初始化语义、界面 probe 和负结果，不宣称算法突破。其定位是可靠证据，不是新模型冠军。
- **等待真正独立的机制**：只有出现满足上述条件的数学设计，才重新评估是否投入训练。现有审计结果仅作限制披露，不再成为拖延机制裁决的工作流。

不得为了“一个月出结果”的时间目标，把旧 JEPA、物理先验或投票包装成创新，也不得用新数据掩盖已测配方的负结果。
